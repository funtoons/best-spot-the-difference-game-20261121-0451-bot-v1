Lantern Lane — a complete spot-the-difference game: two near-identical pictures side by side, markers on the differences found, several still unfound, and a counter of how many remain. Five hand-drawn levels (Harbour Dusk, Night Market, Forest Cabin, Moon Station, Bakery Morning), 8 differences each, a 2:30 clock per level, hints, streak bonuses, synthesized sounds, and a victory screen. Runs offline in a desktop browser from static files, keyboard and mouse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Click a difference in either picture to mark it; H hints, P pauses, R retries the level, M mutes.
